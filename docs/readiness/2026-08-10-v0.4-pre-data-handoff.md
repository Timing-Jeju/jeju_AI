# 제주 하루 여행 MCP v0.4 데이터 투입 직전 인계

## 결론

공개 계약·결정론적 엔진·수집/발행 경계와 생성·정확 일정·실시간 런타임 조립은 준비됐다.
공식 미래 버스는 confirmed 정류장, 서비스달력/stop time, 양 끝 TMAP 도보와 공식 요금
범위를 결합한다. 관련 capability는 실제 publication·coverage·API key가 모두 준비돼야 열린다.
데이터가 없을 때는 숫자나 장소를 추정하지 않고 전체 `insufficient_feasible_routes` 또는
`unverifiable`을 반환한다.

## 구현 완료 범위

- Pydantic v0.4.0 생성·정확 일정·실시간 계약과 여섯 MCP 도구
- 정확히 세 전략, 필수 장소 포함, 관광지 기준 다양성, 60초/40회 hard budget
- 운영시간·입장마감·호텔 왕복·도보·예산·휴식·알레르기·고정수단 판정
- 재검증을 통과한 비파괴 수정안만 반환
- TMAP 보행/차량의 원문·geometry 폐기와 메모리 TTL
- TAGO `arrtime` 60초 snapshot 및 정적 대기시간 교체
- 요청별 Postgres evaluation evidence와 고정 수단별 route 검증
- 공식 시간표 direct bus router와 versioned 제주버스 요금 범위
- TourAPI/TAGO JSON, 특일 XML bounded pagination과 raw-first publication
- 장소·정류장·노선·공휴일 publisher, 입구·mapping·시간표 typed 입력 계약
- 공식 근거 기반 복합 운영시간·예외 휴무 typed 입력 및 publication
- TourAPI 세부 분류 보존과 공식 `A05020900` 카페 판별
- `manual-import` dry-run/raw-first publication 경로
- capability coverage gate와 active snapshot rollback
- 전략별 0~100 근거 점수 및 versioned 내부 정책

## 실제 투입이 필요한 데이터

아래 값은 공식 원문 또는 수동 검증 없이는 만들 수 없다.

1. TourAPI 제주 장소 상세와 날짜별 운영시간
2. 각 숙소·관광지·식당·카페의 보행/차량/접근가능 입구
3. 제주 전역 TAGO 정류장·노선과 canonical stop mapping
4. 시행일이 반영된 제주 공식 시간표, service calendar, trip/stop time, 우회 공지
5. 권역별 `source_coverage` 측정 결과
6. 운영용 TourAPI/TAGO/TMAP API key와 PostGIS/MinIO DSN

수동 데이터 헤더는 `docs/data-templates/`에 있다. 입구는 검증시각·만료·지원수단, 정류장 mapping은 방향·confidence·상태가 없으면 거부된다.

## 실행 순서

```text
1. docker compose -f infra/compose.local.yml up -d
2. uv run python scripts/run_migrations.py --dsn "$JEJU_MIGRATOR_DSN"
3. uv run jeju-data preflight --source tourapi.place
4. uv run jeju-data refresh --profile tourapi-jeju-places --execute
5. uv run jeju-data refresh --profile tago-jeju-bus-routes --execute
6. uv run jeju-data refresh --profile tago-jeju-bus-stops --execute
7. uv run jeju-data refresh --profile holiday-special-days --query-file holiday-years.csv --execute
8. `jeju-data manual-import`로 운영시간·검증 입구·mapping을 dry-run 후 publication
9. 공식 BIS 시간표와 변경 공지를 정규화하고 dry-run 뒤 시간표 import 실행
10. JEJU_ALL/ALL coverage가 1.0인 capability만 활성화
11. 권역별 실제 구간 PoC 후 MCP 운영 연결
```

live 통합 테스트는 개발용 `jeju_trip` DB와 영속 MinIO를 사용하지 않는다. 테스트 전용
서비스는 tmpfs를 사용하므로 컨테이너를 내리면 fixture가 제거된다.

```text
docker compose -f infra/compose.local.yml --profile test up -d postgres-test minio-test
uv run python scripts/run_migrations.py --dsn \
  postgresql://postgres:local-postgres-test-only@127.0.0.1:55433/jeju_trip_test
JEJU_TEST_ADMIN_DSN=postgresql://postgres:local-postgres-test-only@127.0.0.1:55433/jeju_trip_test
JEJU_TEST_S3_ENDPOINT=http://127.0.0.1:59010
```

통합 테스트 session setup은 migration을 적용하고 test MinIO의 `jeju-private-raw` bucket과
versioning을 자동 준비한다. DSN과 endpoint가 지정된 test 전용 대상인지 먼저 검증한다.

`JEJU_TEST_ADMIN_DSN`의 DB 이름이 `jeju_trip_test`가 아니거나 MinIO endpoint가 테스트
포트가 아니면 integration test 수집 단계에서 실행을 거부한다.

`refresh`는 `--execute`가 없으면 네트워크나 저장소를 변경하지 않는 dry run이다. 외부 원문·API key·좌표는 CLI 오류에 출력하지 않는다.

수동 CSV도 `--execute`를 붙이기 전까지 로컬 parsing·정규화만 수행한다.

```text
uv run jeju-data manual-import --dataset place-entrances \
  --file verified-place-entrances.csv --source-date 2026-08-10

uv run jeju-data manual-import --dataset place-opening-hours \
  --file place-opening-rules.csv=verified-opening-rules.csv \
  --file place-schedule-exceptions.csv=verified-exceptions.csv \
  --source-date 2026-08-10

uv run jeju-data manual-import --dataset bus-timetable \
  --file bus-route-stops.csv=route-stops.csv \
  --file service-calendars.csv=calendars.csv \
  --file scheduled-trips.csv=trips.csv \
  --file scheduled-stop-times.csv=stop-times.csv \
  --file service-calendar-exceptions.csv=service-exceptions.csv \
  --file timetable-notices.csv=notices.csv \
  --file route-service-exceptions.csv=route-exceptions.csv \
  --source-date 2026-08-10

uv run jeju-data publish-coverage --publication <active-publication-uuid> \
  --file measured-source-coverage.csv
```

`jeju.bus-timetable`은 2026-08-11 내부 보관·정규화 용도로 승인됐다. `--execute` 전 dry-run과
변경 공지 시행일 검증은 계속 필수이며 원본 파일은 공개 재배포하지 않는다.

## capability 활성화 기준

| flag | 필수 publication |
|---|---|
| `place_search_ready` | 제주 장소·좌표 |
| `opening_hours_ready` | 날짜별 VERIFIED 운영시간 |
| `walking_routing_ready` | 검증 입구 + TMAP 보행 |
| `driving_routing_ready` | 차량 입구 + TMAP 차량 |
| `future_bus_planning_ready` | 시간표·service day·CONFIRMED stop mapping |
| `restaurant_recommendation_ready` | 공식 분류·운영시간·입구 |
| `cafe_recommendation_ready` | 공식 분류·운영시간·입구 |
| `realtime_bus_ready` | TAGO 제주 coverage + ID mapping PoC |
| `accessibility_ready` | accessible 입구 + 계단 검증 경로 |

부분 grid가 성공했다고 제주 전역 flag를 켜지 않는다. `region_code=JEJU_ALL`, `grid_id=ALL`, 해당 여행일 포함, `coverage_ratio=1`, `blocking_reason IS NULL`을 모두 만족해야 한다.
