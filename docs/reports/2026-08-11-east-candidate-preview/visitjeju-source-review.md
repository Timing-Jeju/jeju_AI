## 판정

- 제공기관: 제주관광공사
- 공식 API 가이드: V1.0, 2020년 10월
- 제공 후보: 콘텐츠 ID, 분류, 주소, 대표좌표, 전화번호, 태그, 이미지
- 현재 웹 상세정보 후보: 운영시간, 휴무, 주차, 접근성 안내
- source catalog 등록: 보류
- API 호출: 0건

## 보류 이유

1. 공식 가이드가 `http://` endpoint만 명시한다.
2. 사용 제약 사항이 비어 있어 저장·파생·보존 허용을 확정할 수 없다.
3. 문서가 2020년 버전이라 현재 API 계약과 동일한지 확인이 필요하다.
4. 웹 상세정보가 API 응답에도 포함되는지 가이드만으로 확인되지 않는다.
5. 제공 좌표는 대표좌표이며 검증된 보행·차량 출입구 좌표가 아니다.

## 승인 전 확인사항

- 제주관광공사의 현재 이용 신청 주소와 HTTPS endpoint
- API 원본·정규화 파생 데이터의 내부 저장 허용 범위
- 호출 한도와 갱신주기
- 콘텐츠 ID별 운영시간·휴무·접근성 필드 coverage
- TourAPI fact와의 canonical 장소 매핑 기준

공식 조건이 확인될 때까지 VisitJeju 정보를 운영 evidence나 출입구 fact로 저장하지 않는다.
