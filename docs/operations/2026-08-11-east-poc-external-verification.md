# 제주 동부 PoC 외부 사실 확인 요청서

작성일: 2026-08-11  
대상 여행일: 2026-08-15(광복절)  
상태: 발송 전 초안

이 문서는 공식 웹페이지와 원본 XLSX만으로 확인할 수 없었던 사실을 담당 기관·사업자·현장
검증자에게 묻기 위한 초안이다. 회신 전에는 어떤 값도 운영 fact로 발행하지 않는다.

## 1. 제주 BIS 서비스데이 확인

문의처: 제주버스정보시스템 관련 문의 `064-710-2447`  
공식 시간표 화면: <https://bus.jeju.go.kr/publicTrafficInformation/generalBusSchedule?viewtype=2>

### 요청 문안

> 2026년 8월 15일 토요일(광복절)에 제주 버스 201번, 211번, 212번이 제주 BIS에서 현재
> 제공하는 노선별 XLSX 시간표와 동일하게 운행하는지 확인 부탁드립니다. 공휴일 전용 시간표가
> 있다면 파일 또는 공식 게시물 URL을, 동일 시간표를 적용한다면 ‘공휴일에도 동일 시간표 적용’임을
> 확인할 수 있는 공식 게시물 URL이나 담당 부서의 서면 회신을 부탁드립니다. 일부 운행만 적용될
> 경우 노선·방향·출발시각별 예외도 함께 부탁드립니다.

### 승인 가능한 회신

- 제주 BIS 또는 제주특별자치도 공식 HTTPS 게시물
- 담당 기관이 보낸 날짜·담당 부서가 식별되는 서면 회신과 그 내부 보관 reference
- 공휴일 전용 공식 XLSX와 checksum

전화 통화 메모만으로는 `HOLIDAY` calendar를 발행하지 않는다. 서면 근거에는 최소한
`201`, `211`, `212`, `2026-08-15`, 적용 시간표 또는 예외가 명시돼야 한다.

## 2. 장소 운영시간 확인

각 사업자에게 아래 내용을 요청한다. 입장료·식사비·음료비는 제품 범위가 아니므로 묻거나
수집하지 않는다.

### 공통 요청 문안

> 2026년 8월 15일의 영업 여부와 영업 시작·종료 시각, 마지막 주문/입장 시각을 확인 부탁드립니다.
> 운영시간이 게시된 귀사의 공식 HTTPS 페이지가 있다면 URL을 부탁드립니다. 별도 페이지가 없다면
> 사업자명과 답변일이 식별되는 서면 회신을 부탁드립니다.

### 확인 대상

- 1차 완료 차단 관광지: 광치기해변, 섭지코지, 오조포구
- 운영시간 확보 완료: 성산일출봉, 제주레일바이크
- 식사: 성산 부뚜막식당, 가시아방국수, 백기해녀의집, 지은이네밥상, 부촌
- 휴식: 호랑호랑, 도렐 제주 본점

현재 필수 분모에서는 식사 1곳과 휴식 1곳만 필요하다. primary 후보의 공식 근거가 없으면
fallback 순서에서 운영시간·입구가 모두 확인된 다음 후보로 manifest를 갱신한다.

## 3. 입구 현장 검증

TourAPI·Visit Jeju의 대표 좌표는 입구로 사용하지 않는다. 각 장소에 대해 보행 입구와 차량
승하차 지점을 분리해 확인한다.

### 필수 대상

- `tourapi.place:2757210` 플레이스 캠프 제주
- `tourapi.place:126435` 성산일출봉
- `tourapi.place:2564158` 광치기해변
- `tourapi.place:127813` 섭지코지
- `tourapi.place:2742256` 오조포구
- `tourapi.place:2705373` 제주레일바이크
- 활성 후보로 채택할 식당과 카페

### 현장 검증 기록 요건

- WGS84 위도·경도와 입구 유형(`pedestrian`, `vehicle`, `main`, 필요 시 `accessible`)
- 검증 일시, 검증 방법, 만료일, 지원 이동수단
- 현장에서 입구임을 확인할 수 있는 표지·주소·시설 관계
- 개인정보가 없는 사진 또는 공식 시설 안내도의 private reference
- 행별 HTTPS 또는 내부 승인 reference

좌표는 `docs/data-templates/place-entrances.csv` 형식으로 작성하고, dry-run 검증 전까지
`UNVERIFIED` 상태를 유지한다. 사진 원본은 공개 저장소에 커밋하지 않는다.

## 4. 회신 후 실행 순서

1. 회신 원문 checksum과 source reference를 private raw에 등록한다.
2. 서비스데이, 운영시간, 입구 CSV를 각각 dry-run 한다.
3. 모두 통과한 레코드만 `STAGED` publication으로 만든다.
4. `JEJU_EAST/POC_V1` manifest의 필수 구성원을 확정한다.
5. exact-scope coverage가 1.0인지 측정한 뒤 원자적으로 activate 한다.
6. recommend → evaluate → synthetic revalidate를 다시 실행한다.
7. 2026-08-15 당일 TAGO 도착정보 smoke까지 통과한 뒤에만 `Pass`로 승격한다.

현재는 위 회신이 없으므로 운영 상태는 `Partial`이며, `BUS_SERVICE_DAY_UNVERIFIED`,
`OPENING_HOURS_UNVERIFIED`, `VERIFIED_ENTRANCE_MISSING`을 유지한다. 동부 scope manifest와
2026-08-15 버스·택시 운임 정책은 이미 활성화됐지만, 이 세 외부 사실을 대신하지 않는다.

## 5. 1차 사용자 가치 경로

운영 승격을 기다리는 동안 별도 staging 프리뷰는 다음 범위까지 제공한다.

- 서로 다른 전략 3개와 실제 이름이 있는 식사·휴식 장소
- 정책 기반 체류시간·점심 시간창·숙소 복귀 경계
- 프로세스 메모리에서만 사용한 TMAP 자동차 route fact
- 공식 택시 운임 정책에 따른 택시비 범위

프리뷰는 대표좌표를 `provisional_place_center`로 명시하고 `production_recommendation=false`를
유지한다. 버스 공휴일 근거가 없다고 택시로 조용히 우회하지 않으며, 입구·운영시간 미확정과
택시 배차 비보장도 일정별 issue로 노출한다. 이 경로는 좋은 후보를 먼저 보여주기 위한
비운영 결과이며 공개 `recommend_jeju_day_trips`의 성공 응답을 대체하지 않는다.
